# 性能基准说明

本项目不按平台 200 名用户构造 200 个并发全量请求。一次 gRPC 接口会扇出数万条数据库记录和 RabbitMQ 消息，主要压力单位是单次用例数和同时运行的批量任务数。

完整的测试环境初始化、交叉编译、单次全量基准、低并发容量验证、指标采集、对账 SQL、停止条件和回退流程，统一放在：

[公司测试环境初始化与性能基准攻略](../scripts/benchmark/README.md)

推荐口径：固定同一批 52,265 条用例，预热 1 次，正式执行 3～5 次；报告总耗时中位数和 P95、吞吐、首帧耗时、CPU/RSS 峰值，以及 execution、outbox、MQ、Python 回调四方对账结果。
